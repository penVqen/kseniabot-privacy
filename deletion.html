Удаление данных KseniaBot

Чтобы запросить удаление данных взаимодействия с ботом, напишите в Direct @ksenia_zaitseva87.

  1. Укажите Instagram username аккаунта, с которого вы общались с ботом.
  2. Напишите: «Прошу удалить мои данные взаимодействия с KseniaBot».
  3. При необходимости владелец аккаунта уточнит сведения для подтверждения запроса.

Запрос обрабатывается вручную владельцем аккаунта и обслуживающими сервис лицами. Удаляются связанные с взаимодействием записи из базы приложения и технической очереди. Подтверждение обработки запроса отправляется в Direct. Удаление из приложения не удаляет переписку и данные, которые отдельно хранит Instagram.

Бот не запрашивает имя и номер телефона; технические события могут содержать текст сообщений, который пользователь отправил самостоятельно.
